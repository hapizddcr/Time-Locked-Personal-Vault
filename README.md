# Time Locked Personal Vault

Smart contract Solidity yang memungkinkan pengguna mengunci ETH hingga waktu tertentu.

## Features

- Deposit ETH
- Withdraw setelah unlock
- Extend lock
- Owner only
- Custom Errors
- Event Logging

## Tech Stack

- Solidity
- Hardhat 3
- TypeScript
- Ethers.js

## Deploy

```bash
npx hardhat run scripts/deploy.ts --network sepolia
```

## Compile

```bash
npx hardhat compile
```

## Test

```bash
npx hardhat test
```
